slotLane is built to do one thing well. This is what it does not do.

## One owner's calendar

Built for one owner's calendar: one admin account and one set of availability. Teams, round-robin and multi-host pages are not supported yet. The workaround is one booking page per person.

## Google Calendar only

slotLane syncs with Google Calendar. It checks busy times and writes bookings there. Syncing with Outlook, Microsoft 365 or iCloud is not supported. Invites are standard .ics files, so they open in Outlook and Apple Calendar.
