Your booking page shows guests only the times you are actually free, after your buffers, notice and Google Calendar busy times.

## Before you start

- [Google Calendar connected](/docs/guides/google-calendar).
- A rough idea of your weekly rhythm: when you take meetings, and when you never do.

## Settings

| Setting | What it controls |
| --- | --- |
| Weekly hours | The recurring times you can be booked, per day. Several ranges per day are supported, for example 09:00–12:00 and 14:00–17:00. |
| Slot length | The size of the bookable steps guests see. |
| Buffer | Protected time before and after each booking, so meetings do not run into each other. |
| Minimum notice | How far ahead a guest must book. No surprise meetings in an hour. |
| Booking window | How far into the future guests can book. |

## Event types

Create as many event types as you need: intro calls, demos, strategy sessions. Each has its own link, length, description and location. Google Meet or Zoom, with the link created for you.

## Common mistakes

- Forgetting the buffer. Back-to-back bookings with no gap is the top regret. Start with 10–15 minutes.
- A booking window that is too short. If guests regularly book two or three weeks out, give them room.
- Checking the wrong calendars. If you keep personal appointments on a second calendar, include it in the busy check, or those times will look free.
